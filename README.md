# Internship_C-DAC_Bengaluru_project
📝 Handwritten Answer Sheet Evaluator (OCR + NLP)

An AI-based system that automates the evaluation of handwritten answer sheets using OCR and NLP techniques. Developed during my internship at C-DAC Bengaluru.

🚀 Features
Extracts handwritten text using OCR
Processes text with NLP techniques
Compares answers using cosine similarity
Generates automated evaluation scores
⚙️ Tech Stack

Python • EasyOCR/Tesseract • TF-IDF • Scikit-learn • OpenCV

💡 Goal

To reduce manual effort and improve accuracy in answer sheet evaluation using AI.
